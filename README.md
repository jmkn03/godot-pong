# **godot-pong**

### My first Godot project, a simple pong game

### **NOTES:**
- *This is an unfinished project that I put to the side recently. I'm looking forward to continuing it in order to better understand how game engines work.*
- *The project was created while learning Godot, mostly from YouTube tutorials.*
- *Single Player feature does not work yet. If selected the game works in multiplayer.*
- *Player 1 (Left) moves using W-S keyboard keys and player 2 (Right) moves using Up-Down keyboard keys.*
